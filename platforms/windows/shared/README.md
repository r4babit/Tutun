# Общий контракт Tutun

- `schemas/tutun-profile-v1.schema.json` — JSON Schema формата обмена.
- `examples/empty-profile.tutun.json` — пустой профиль с настройками по умолчанию.
- `examples/demo-profile.tutun.json` — синтетический сервер `proxy.example.invalid`, без реальных ключей.
- `brand/tokens.json` — цвета и выбранный исходник значка.

Корневые поля: `format = "tutun.profile"`, `schemaVersion = 1`, `servers`, `subscriptions`, `routingProfiles`, `preferences`. Даты — UTC ISO 8601. Неизвестная версия отклоняется; добавление обязательных полей требует миграции или новой версии. Схема проверяет структуру; уникальность ID и ссылки между элементами дополнительно проверяются кодом.

`preferences` содержит только общие сетевые настройки. Из экспорта исключены HWID, права, локальные порты, автозапуск, Wi-Fi-автоматизация, уведомления, видимость Dock, журналы, статистика и правила приложений (имя процесса macOS нельзя переносить как Android package ID). Значения `AppSettings` в Swift — модель совместимости текущего клиента; её нельзя целиком применять на другой платформе.

Это формат обмена, а не синхронизация и не хранилище живого приложения. Экспорт/импорт пока доступны как библиотечный конвертер. Серверные outbounds сохраняются в `outboundJSON`; перед запуском их нужно проверить отдельно и адаптировать к поддерживаемому ядру.

Файл реального профиля содержит секреты: URL подписок, ключи и rawLink. Его нельзя коммитить или писать в журнал; хранение на устройстве должно быть приватным. Примеры здесь используют только синтетические данные.
